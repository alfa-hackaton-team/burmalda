# burmalda

Сервис новостной аналитики для принятия бизнес-решений. Он сопоставляет внешние события с особенностями компании, объясняет возможные последствия и показывает, на каких данных и материалах Альфа-Банка основан вывод.

## Запуск

Нужен Docker с Compose. Из корня репозитория:

```sh
docker compose up -d --build
```

Команда поднимает PostgreSQL, локальное S3-совместимое хранилище, создаёт bucket, применяет миграции, проверяет и загружает [исходный набор данных](data/hackathon/README.md), затем запускает API, воркер опроса и ML-заданий, сборщик состояния, очистку истории и сверку оригиналов. Prometheus, Loki, Tempo, Alloy и Grafana запускаются вместе с ними. Проверка: `docker compose ps` и `curl http://127.0.0.1:18080/health/ready`. Grafana доступна по адресу [http://127.0.0.1:13000](http://127.0.0.1:13000). Остановить процессы: `docker compose down`; данные PostgreSQL остаются в `docker-volume/postgres`, остальные persistent-данные — в Docker volumes.

Локальные пароли и ключи в Compose предназначены только для проверки на своей машине. В частности, для подписи курсоров задан локальный `CURSOR_SIGNING_KEY`, поэтому базовый Go-запуск не требует подготовки `.env`; вне локального Compose его необходимо заменить случайным 32-байтовым ключом в Base64. ML1/ML2 реализованы отдельным Compose-профилем. Для полного Go → ML запуска скопируйте `.env.example` в `.env`, задайте ключ gateway и выполните команду из [инструкции по запуску ML](docs/ml/docker.md). Без `ML_PIPELINE_VERSION` Go не создаёт ML-задания. Лимит текста — 131072 байта. API подключает `/v0.1/me`, `/v0.1/contexts`, `/health/live` и `/health/ready`. Подробности — в [документации бэкенда](backend/README.md).

Импортированные банковские PDF проходят через общий поток `article_versions` → `processing_jobs`; при пустой версии ML-пайплайна задания не создаются. Для передачи нормализованных CSV по запросу ML можно задать `DATASET_API_TOKEN` и использовать закрытый API `/internal/v0.1/datasets/active`. Формат его использования с ML пока не согласован; детали — в [описании набора](data/hackathon/README.md).
