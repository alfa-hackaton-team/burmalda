# burmalda

Сервис новостной аналитики для принятия бизнес-решений. Он сопоставляет внешние события с особенностями компании, объясняет возможные последствия и показывает, на каких данных и материалах Альфа-Банка основан вывод.

## Запуск

Нужен Docker с Compose. Из корня репозитория:

```sh
docker compose up -d --build
```

Команда поднимает PostgreSQL, локальное S3-совместимое хранилище, создаёт bucket, применяет миграции и запускает API, воркер опроса и ML-заданий, сборщик состояния, очистку истории и сверку оригиналов. Prometheus, Loki, Tempo, Alloy и Grafana запускаются вместе с ними. Проверка: `docker compose ps` и `curl http://127.0.0.1:18080/health/ready`. Grafana доступна по адресу [http://127.0.0.1:13000](http://127.0.0.1:13000). Остановить процессы: `docker compose down`; данные останутся в Docker volumes.

Локальные пароли и ключи в Compose предназначены только для проверки на своей машине. ML-сервис и фронтенд в этом репозитории пока не реализованы. Чтобы подключить отдельный ML-сервис, задайте согласованные `ML_PIPELINE_VERSION`, `ML_MAX_TEXT_BYTES`, `ML_BASE_URL` и `ML_SERVICE_TOKEN` перед запуском. Без них воркер загружает материалы, но не создаёт ML-задания. Пользовательские маршруты API пока не подключены: `/health/live` и `/health/ready` проверяют работу API и БД. Подробности — в [документации бэкенда](backend/README.md).
