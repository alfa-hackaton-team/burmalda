# burmalda

Сервис новостной аналитики для принятия бизнес-решений. Он сопоставляет внешние события с особенностями компании, объясняет возможные последствия и показывает, на каких данных и материалах Альфа-Банка основан вывод.

Документация проекта:

- [Обзор документов](docs/README.md) — навигация и порядок чтения.
- [PRD](docs/product/PRD.md) — пользователи, возможности продукта и критерии качества.
- [Архитектура](docs/architecture/architecture.md) — устройство системы, потоки данных и взаимодействие компонентов.
- [Контракты API](docs/api/README.md) — форматы обмена между интерфейсом, сервером и ML-сервисом.
- [Go-бэкенд](backend/README.md) — локальный запуск API, воркера и PostgreSQL.

Описание запуска, окружения и зависимостей размещается рядом с реализацией соответствующих компонентов.
