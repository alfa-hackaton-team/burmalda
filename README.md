# burmalda
Сервис новостной аналитики для принятия бизнес-решений

Первоначальный проект системы, версия 0.1: [навигация по документам](docs/README.md),
[PRD](docs/product/PRD.md), [архитектура](docs/architecture/architecture.md).

Документы находятся на рассмотрении команды: принятые требования, проектные предложения
и открытые решения (TBD) разделены в [реестре решений](docs/planning/decision-register.md).
Код приложения и инструкция по запуску появятся на этапе реализации.
