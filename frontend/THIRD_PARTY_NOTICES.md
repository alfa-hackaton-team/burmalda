# Сторонние компоненты frontend

Точные версии прямых и транзитивных зависимостей зафиксированы в `package-lock.json`.
Лицензии отдельных пакетов находятся в соответствующих пакетах `node_modules`.
Этот перечень относится к frontend; он не заменяет перечень компонентов всего проекта.

- Core Components и корпоративная тема Альфа-Банка — MIT:
  https://github.com/core-ds/core-components.
- React и React DOM — MIT: https://github.com/facebook/react.
- Lucide React — ISC: https://github.com/lucide-icons/lucide.
- Vite, Vitest, TypeScript, Prettier, Testing Library и jsdom используются
  как инструменты разработки и проверки; лицензии включены в установленные пакеты.
- Node.js и nginx используются в Docker-образах; их лицензии и лицензии базовых
  образов распространяются вместе с соответствующими образами.

Имитации: банковская оболочка, учетная запись, компании, события, аналитические
выдержки, ответы, трассировка и оценки в режиме `demo` являются синтетическими.
Этот режим не использует LLM и не является интеграцией с реальным интернет-банком.
В режиме `api` frontend подключается только к публичному Go API проекта.
Фирменные шрифты и отдельный официальный логотип не включены: используется
системный шрифт и текстовое обозначение прототипа.
