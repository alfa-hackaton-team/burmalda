## Готовность контрактов

Пути и поля API предложены для согласования и имитаций, а не объявлены принятыми решениями. Авторизационные схемы намеренно не заданы (Q01); это не анонимный публичный API. Q07 оставляет порядок получения результата открытым, в спецификациях отмечены альтернативные ответы. Q14 не позволяет считать DTO физической схемой БД.

Для реализации требуется согласовать стабильную часть контрактов, отдельно принять порядок выполнения и границу авторизации. ML-эксперименты могут независимо выполняться на синтетических данных с явно заданными контекстами.
