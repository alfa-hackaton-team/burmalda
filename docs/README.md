# Первоначальный проект системы v0.1

Версия: 0.1. Дата: 2026-10-22. Статус комплекта: DRAFT, на рассмотрении команды.

После согласования и объединения изменений с `main` принятые разделы становятся основным источником проектных решений. Пункты TBD остаются открытыми до отдельного решения; статус DRAFT не означает, что все предложенные контракты утверждены.

## Классификация

- CASE REQUIREMENT — прямое требование PDF кейса; страница источника указана в матрице.
- TEAM DECISION — согласованное исходное решение команды.
- ASSUMPTION — проектное предложение этого комплекта; оно требует проверки и согласования перед реализацией.
- TBD — решение ещё не принято; варианты, критерии выбора и нужный эксперимент находятся в реестре.
- FUTURE — возможность за пределами v0.1; учитываем развитие архитектуры без добавления инфраструктуры сейчас.

Требования и решения имеют идентификаторы Cxx, Dxx, Qxx, FRxx, NFRxx. Изменения форматов обмена данными (DTO) согласуются одновременно в двух API и использующих их документах. Физическая схема из `feature/db-rfc` предварительная; её согласование и сверка с предметной моделью обязательны до реализации хранения.

Риски, этапы реализации и распределение ответственности находятся в [архитектуре](architecture/architecture.md#риски-реализации).
